Build a complete, reliable **iNaturalist dataset downloader** for AnimalVision.

The goal is to automatically create a balanced dataset of **1,000 images total** for these 15 classes:

* bear
* cat
* deer
* dog
* elephant
* fox
* giraffe
* horse
* lion
* monkey
* panda
* rabbit
* tiger
* wolf
* zebra

Target roughly **66–67 images per class**.

## Requirements

### iNaturalist

* Use the public **iNaturalist API**.
* Do not scrape iNaturalist webpages.
* Do not require an API key.
* Search observations by the correct taxon/species.
* Download the actual observation image URLs.
* Prefer reasonably high-quality images.

### Dataset structure

Create:

```text
dataset/
├── bear/
├── cat/
├── deer/
├── dog/
├── elephant/
├── fox/
├── giraffe/
├── horse/
├── lion/
├── monkey/
├── panda/
├── rabbit/
├── tiger/
├── wolf/
└── zebra/
```

Save images directly into the appropriate class directory.

### Image validation

Every downloaded image must be checked with Pillow.

Skip:

* corrupt images
* empty files
* files that aren't images
* unsupported formats
* extremely tiny images
* duplicate images
* gifs

Convert valid images to a consistent format such as JPEG if necessary.

Use safe filenames.

### Reliability

The downloader must:

* resume interrupted downloads
* never delete existing valid images
* skip images that were already downloaded
* retry temporary network failures
* use request timeouts
* handle HTTP errors gracefully
* handle iNaturalist rate limiting
* continue if an individual image fails
* continue downloading other classes if one class has problems
* never crash because of one bad image

Keep dependencies minimal and make it work well in **Termux on Android**.

### Progress

While downloading, show simple progress such as:

```text
AnimalVision Dataset Downloader

cat        [████████████████░░░░] 52/67
dog        [██████████████░░░░░░] 47/67
...
```

Don't flood the terminal with hundreds of lines.

At the end show:

```text
DOWNLOAD COMPLETE

bear       67
cat        67
deer       66
...

Total: 1000
```

If some classes couldn't reach their target, clearly show:

```text
WARNING: Dataset is incomplete.

tiger: 61/67
Reason: not enough usable images found.

Total: 994/1000
```

### Beginner-friendly usage

The normal command should simply be:

```bash
python scripts/download_dataset.py
```

It should automatically:

1. create directories
2. find the correct iNaturalist taxa
3. download observations
4. validate images
5. remove/skip invalid downloads
6. balance the classes
7. print the final summary

Also support optional commands:

```bash
python scripts/download_dataset.py --verify
python scripts/download_dataset.py --resume
python scripts/download_dataset.py --class cat
```

`--verify` should scan the existing dataset without downloading anything.

`--resume` should continue an incomplete dataset.

`--class cat` should download/fill only the selected class.

Do not make command-line arguments necessary for normal use.

### Important

Do not use random images from Google or image scraping.

Use **iNaturalist observations only**.

Keep the code short, clean, readable, and reliable rather than over-engineering it.

Create any required helper files and update `requirements.txt` with only the dependencies actually needed.
